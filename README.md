# AkkMusic

Простой аудиоплеер для локальных файлов на Android (Kotlin + Media3 / ExoPlayer).

Что уже есть:
- библиотека из системного индекса (MediaStore), сортировка по исполнителю → альбому → номеру трека;
- фоновое воспроизведение с уведомлением и кнопками на экране блокировки;
- управление с Bluetooth-наушников и часов (через медиасессию);
- пауза при звонке и при отключении наушников, приглушение под навигатор;
- очередь, перемешивание, повтор (всё / один трек), перемотка;
- плейлисты: создание, переименование, удаление, добавление трека долгим нажатием, перестановка перетаскиванием.

Минимальная версия Android — 8.0.

## Как получить APK

Каждое изменение в ветке `main` автоматически собирается и публикуется
во вкладке **Releases** репозитория как файл `AkkMusic-1.N.apk`.
Там всегда лежит последняя версия, помеченная как Latest.

### Сборка вручную

#### Вариант 1: GitHub (без установки чего-либо)
1. Создай пустой репозиторий на github.com (можно приватный).
2. Загрузи туда все файлы этой папки (кнопка «Add file → Upload files», перетащи содержимое,
   включая скрытую папку `.github`).
3. Открой вкладку **Actions** — сборка запустится сама, займёт 3–5 минут.
4. Открой завершённую сборку, внизу в **Artifacts** скачай `AkkMusic-apk`, внутри APK.
5. Перекинь APK на телефон и установи (разреши установку из неизвестных источников).

#### Вариант 2: Android Studio
Открой папку проекта в Android Studio, дождись синхронизации, нажми Run
(или Build → Build APK(s)).

## Про подпись
Приложение подписано ключом `app/debug.keystore` (пароль `android`). Он лежит в проекте,
чтобы каждая новая сборка ставилась поверх старой. Для личного использования этого достаточно,
для публикации в магазине нужен свой ключ.

## Если плеер останавливается в фоне
На Xiaomi, Huawei, Samsung и некоторых других прошивках: Настройки → Приложения → AkkMusic →
Батарея → «Без ограничений». Инструкции под конкретные модели: https://dontkillmyapp.com
